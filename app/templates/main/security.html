Privacy & PC Safety Guarantee

Security & Local PC Architecture

DevHub is architected from the ground up to ensure you can run, test, and host your developer social network without any risk to your personal computer, operating system, or private data.

Local-First Sandbox

The application binds to your machine's loopback interface (127.0.0.1) by default. It does not open exposed firewall ports, does not communicate with external tracking servers, and requires no administrative privileges.

Cryptographic Password Hashing

Passwords are never stored in plaintext. They are protected using memory-hard cryptographic key derivation functions (scrypt / pbkdf2:sha256) with individual cryptographic salts, preventing rainbow table and brute-force attacks.

Strict XSS & HTML Sanitization

Markdown in posts, comments, and project README files is strictly sanitized via bleach with an allowed whitelist. Malicious scripts, event handlers (onload, onerror), and iframe exploits are stripped out automatically.

Path Traversal & ZIP Safety

Project downloads stream ZIP files directly in memory using Python's standard library. File access strictly validates directory boundaries (os.path.commonpath), completely preventing malicious file viewing outside the sandbox.
